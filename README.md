# Saltify

Saltify is a fork of [Astrofy](https://github.com/manuelernestog/astrofy), with the goal of expanding on its functionalities and customization.

I highly recommend reading the original repo's README.

## Installation & Usage

Make sure you have [pnpm](https://pnpm.io/installation) installed.

Clone the repo, then run the following command in your terminal.

```bash
pnpm install
```

Then, either run the following command, or open the project in Visual Studio Code and press F5.

```bash
pnpm run dev
```

## Deploy

See the [official Astro information](https://docs.astro.build/en/guides/deploy/) to deploy your website.
